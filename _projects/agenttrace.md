AgentTrace is a schema-based logging framework for real-time observability, accountability, and security in LLM-powered agent systems.

The framework organizes traces across cognitive, operational, and contextual surfaces, making it easier to reconstruct agent behavior and identify the source of failures across tools, models, and environments.
